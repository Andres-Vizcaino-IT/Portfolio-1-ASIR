#  Portfolio de LMSGI - 1º ASIR

¡Bienvenido a mi portfolio del módulo de **Lenguajes de Marcas y Sistemas de Gestión de Información (LMSGI)**! 

En este repositorio recojo todas las prácticas y laboratorios que he desarrollado durante el curso. El objetivo de este portfolio es demostrar mi aprendizaje y evolución en el desarrollo web, estructurando la información mediante HTML5 y dándole formato mediante CSS.

A continuación, detallo los conocimientos aplicados divididos por bloques temáticos:

---

## 📝 Texto e Imágenes
En este bloque senté las bases del lenguaje HTML, aprendiendo a estructurar semánticamente el contenido y a enriquecerlo visualmente.
* **Estructura básica:** Uso de encabezados (`<h1>` a `<h6>`), párrafos (`<p>`), e incrustación de caracteres especiales (nemotécnicos).
* **Formato de texto:** Aplicación de negritas (`<strong>`), cursivas (`<em>`), subrayados y saltos de línea (`<br>`).
* **Imágenes:** Inserción de imágenes (`<img>`) controlando sus atributos de origen (`src`), texto alternativo (`alt`), y ajustes básicos de tamaño.
* **Listas:** Creación y anidación de listas ordenadas (`<ol>`) y desordenadas (`<ul>`) con diferentes tipos de viñetas (círculos, cuadrados, números romanos).

## 🔗 Enlaces y más (Multimedia e Interactividad)
Aquí la web dejó de ser estática para convertirse en un entorno navegable y multimedia.
* **Hipervínculos:** Creación de enlaces (`<a>`) a páginas externas, correos electrónicos (`mailto:`) y anclas internas para navegar dentro de la misma página.
* **Mapas de imágenes:** Uso de las etiquetas `<map>` y `<area>` para crear zonas interactivas y clicables dentro de una misma imagen (como en la práctica de Silent Hill 2).
* **Multimedia HTML5:** Integración nativa de bandas sonoras y vídeos usando las etiquetas `<audio>` y `<video>`, configurando atributos como `controls`, `autoplay`, `loop` y `muted`.
* **Iframes:** Incrustación de otras páginas web dentro del documento principal mediante la etiqueta `<iframe>`.

## 📊 Tablas
Dominio profundo de la estructuración de datos bidimensionales y maquetación clásica mediante tablas.
* **Estructura:** Uso avanzado de `<table>`, `<tr>`, `<td>`, y `<th>`.
* **Agrupación semántica:** División de las tablas usando `<thead>`, `<tbody>`, `<tfoot>` y `<colgroup>` para un control más fino.
* **Fusión de celdas:** Expansión de filas y columnas mediante los atributos `rowspan` y `colspan` para crear estructuras complejas (ej. horarios, catálogos).
* **Maquetación clásica:** Uso de tablas anidadas y alineaciones para diseñar la estructura visual de páginas completas (ej. portadas de noticias, despachos de abogados).

## 📋 Formularios
Creación de interfaces para la recogida y validación de datos del usuario, aprovechando todo el potencial de HTML5.
* **Estructura y Envío:** Uso de la etiqueta `<form>` configurando métodos de envío (`GET`/`POST`), la acción (`action`) y el tipo de codificación (`enctype`). Agrupación lógica con `<fieldset>` y `<legend>`.
* **Controles clásicos:** Implementación de campos de texto, contraseñas, áreas de texto (`<textarea>`), menús desplegables (`<select>`, `<optgroup>`), casillas de verificación (`checkbox`) y botones de opción (`radio`).
* **Nuevos controles HTML5:** Integración de campos avanzados como `number`, `range`, `color`, `date`, `email` y subida de archivos múltiples (`<input type="file" multiple>`).
* **Asistencia y Validación:** Mejora de la experiencia de usuario (UX) mediante `placeholder`, `autofocus`, listas de sugerencias (`<datalist>`) y el cálculo dinámico de resultados (`<output>`). Validación estricta con atributos como `required`, `maxlength` y expresiones regulares (`pattern`).

## 🎨 CSS Básico
El paso definitivo para separar el contenido de la presentación y dotar a la web de un aspecto profesional y adaptable.
* **Integración de estilos:** Aplicación de CSS en línea (atributo `style`), embebido (`<style>`), en archivos externos (`<link>`) e importaciones (`@import`).
* **Selectores y Cascada:** Uso de selectores de etiqueta, identificadores (`#id`) y jerarquía. Comprensión de la herencia y el uso de `!important` para forzar reglas.
* **Formato Avanzado:** Control exhaustivo de la tipografía (fuentes de respaldo), alineaciones, espaciados (`letter-spacing`, `line-height`), colores (RGB, HSL, opacidad) y fondos (imágenes repetidas, fijas o adaptadas con `background-size: cover`).
* **Unidades de medida:** Transición de unidades absolutas (`px`, `pt`) a unidades relativas y de viewport (`em`, `%`, `vh`, `vw`) para mejorar la accesibilidad.
* **Diseño Responsivo (Media Queries):** Creación de hojas de estilo alternativas y uso de `@media` para adaptar el diseño según el dispositivo de salida (pantalla `screen`, impresora `print`, móviles `handheld` o anchos máximos de ventana).
